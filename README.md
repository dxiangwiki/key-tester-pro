# README\.md

\# Key Tester Pro 专业键盘按键检测工具

网页版键盘按键检测器，支持捕获键盘按键、查看原生 key/code/keyCode，可开关拦截浏览器默认快捷键（F5刷新、F11全屏等）。纯前端单HTML文件，开箱即用。

## ✨ 功能特性

1\. **实时按键捕获**

- 页面中央实时显示当前按下的按键，松开自动恢复「等候按键」

- 可开启/关闭显示底层按键信息：`code`、`keyCode`

2\. **浏览器快捷键拦截开关**

- 开启后可阻止浏览器原生快捷键行为：F5刷新、Ctrl\+R、F11全屏、F12开发者工具等

- ⚠️ 限制：拦截能力受浏览器版本安全策略影响，部分浏览器可能无法拦截部分系统按键

3\. **专业UI界面**

- 深色科技风 \+ 玻璃拟态卡片，按键文字带发光效果

- 顶部2个滑动开关，状态实时同步

- 实时状态指示灯：Key状态、Code显示状态、快捷键拦截状态

4\. **长按防抖**：按住按键不会重复刷屏刷新页面文字

5\. **移动端自适应**，在手机浏览器也可以打开（但手机无物理键盘，主要用于电脑）

## 📦 使用方法

1\. 新建文本文件，将html代码完整复制进去

2\. 文件另存为：`key-tester-pro.html`，编码选择 UTF\-8

3\. 使用浏览器直接打开该文件（推荐 Chrome / Edge）

4\. **使用前必须点击页面激活焦点**，否则无法捕获键盘按键！

### 操作说明

- `显示Code信息`：开启后，按键下方小字展示 `code` 和 `keyCode`

- `拦截浏览器快捷键`：开启后屏蔽浏览器自带快捷键功能（F5/F11/F12等）

## ⚠️ 重要注意事项

1\. **页面焦点**：窗口必须激活（点击页面任意位置），按键监听才生效。页面失去焦点时无法捕获按键。

2\. **浏览器安全限制**

- F11全屏拦截：部分新版浏览器会限制JS拦截F11；你当前使用的浏览器版本支持拦截

- F12开发者工具：部分浏览器新版本无法拦截打开开发者工具

- 一旦进入浏览器原生全屏模式，Esc/F11按键可能无法被JS捕获

3\. 仅在本地浏览器打开使用，不建议部署到公网网站用于生产。

4\. 本工具仅用于前端开发调试按键码，请勿用于其他违规用途。
